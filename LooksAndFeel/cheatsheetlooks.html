Normalization

  • 1NF → Atomic values only
  • 2NF → Remove partial dependency
  • 3NF → Remove transitive dependency

SQL Joins

  • INNER JOIN → Matching rows only
  • LEFT JOIN → All left rows
  • RIGHT JOIN → All right rows
  • FULL JOIN → Everything
